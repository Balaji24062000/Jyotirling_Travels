BUILD THE APK (no Android Studio needed)
1. Open www/index.html and set API, RZP_KEY, GMAPS, FARE, UPI at the top of the script.
2. Create a free GitHub account, make a new repository, and upload ALL files of this folder
   (including the hidden .github folder) to the main branch.
3. Open the repository > Actions tab > "Build APK" > Run workflow. Wait about 5-8 minutes.
4. Open the finished run > Artifacts > download "Jyotirling-APK" > unzip > app-debug.apk.
5. Copy app-debug.apk to an Android phone and install (allow "Install unknown apps").
For the Google Play Store you need a signed release (AAB) build; ask for that when ready.
